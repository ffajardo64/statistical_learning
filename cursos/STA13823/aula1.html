Um pouco de historia…

O \(\TeX\) é um sistema de tipográfico produzido (desenhado e escrito) principalmente por Donald Knuth, da Universidade de Stanford, e lançado em 1978.

O \(\TeX\) foi concebido sob dois pilares fundamentais:

  • Permitir a produção de obras de alta qualidade com esforço reduzido; e
  • Garantir a consistência absoluta dos resultados, independentemente do hardware ou do tempo decorrido.

Por ser um software livre, ele democratiza o acesso à tipografia de ponta. Amplamente reconhecido pela sofisticação no processamento de fórmulas matemáticas complexas, o sistema tornou-se o padrão em áreas como Estatística, Matemática, Física, Engenharias, entre outras.

Algumas características

  • Codificação em Texto Plano (Plain Text): Diferente de processadores de texto binários (como o .doc ou .docx antigos), o código-fonte do \(\TeX\) é composto apenas por caracteres ASCII. Isso significa que:
  1. Pode ser lido e editado em qualquer editor de texto, do mais simples (Bloco de Notas, Vim, Gedit) ao mais avançado (VS Code, Texmaker);
  1. O arquivo é extremamente leve e imune à corrupção de arquivos binários complexos;
  1. É ideal para sistemas de controle de versão (como o Git), pois permite visualizar exatamente o que foi alterado linha por linha.
  • Estabilidade Temporal e de Software: O algoritmo de quebra de parágrafos e hifenização do \(\TeX\) foi projetado por Donald Knuth para ser matematicamente preciso.

Algumas características

  • Reprodutibilidade: Se você processar um arquivo \(\TeX\) escrito em 1982 em um computador de 2026, o posicionamento de cada letra e símbolo no arquivo final (PDF ou DVI) será rigorosamente o mesmo;
  • Consistência entre Sistemas Operacionais: Não importa se você está no Windows, Linux ou macOS; os motores de renderização (pdfTeX, XeTeX, LuaTeX) seguem as mesmas regras métricas;
  • A “Abstração” da Interface: Ao escrever apenas com símbolos do teclado, o autor se preocupa com a estrutura lógica (o conteúdo) e deixa a apresentação visual (o layout) para o compilador. Isso evita o problema comum de “objetos que se movem sozinhos” ao abrir um arquivo em computadores com versões de softwares diferentes.

\(\LaTeX\)

Uma variante do \(\TeX\) é o \(\LaTeX\), desenvolvido por Leslie Lamport em 1985.

O \(\LaTeX\) consiste em um conjunto de macros ou rotinas \(\TeX\) que facilitam os procedimentos de edição.

Estrutura de um documento \(\LaTeX\)

O arquivo fonte pode ser criado com qualquer editor de texto, utilizando todos os caracteres de um teclado usual, excetuando os simbolos: \ { } $ % & # ~ ^ _ |

O simbolo \ (backslash) é utilizado no inicio de TODO comando ou instrução do \(\LaTeX\), por exemplo: \S (\(\S\)), \LaTeX (\(\LaTeX\)), \rightarrow (\(\rightarrow\)), entre outros*

O \(\LaTeX\) processa o texto do arquivo fonte basicamente em 3 modos:

  • Modo normal ou modo de parágrafo: Essa é a forma natural. O texto é separado por linhas, parágrafos e páginas;
  • Modo LR (esquerda-direita): Parecido com o modo normal, exceto que \(\LaTeX\) escreve indefinidamente de esquerda à direita e nunca começa uma nova linha;
  • Modo matemático: é o modo utilizado para a escrita de símbolos matemáticos. Para tal situação, requer-se o uso dos símbolos $, $$ ou \[.

Exemplo 2  

\textbf{Lei Fraca doa Grandes Números} 

Seja $X_1, X_2, \ldots, X_n$ uma sequência de vari\'aveis alea\'orias independentes 
e identicamente distribuídas e integr\'aveis, com m\'edia $\mu$. Ent\~ao:

$$\mathbb{P}\left(\left|\frac{1}{n}\sum_{i=1}^nX_i-\mu\right|<\epsilon\right)\to1,\quad \text{quando } n\to\infty.$$

Algumas considerações

  • Espaçamento entre palavras: \(\LaTeX\) ignora qualquer espaçamento seguido de um outro espaçamento, i.e., para \(\LaTeX\) é igual 1 ou 10 espaços entre palavras. Existe controle automático de espaçamentos entre palavras;
  • Espaçamento entre parágrafos: Igual que entre palavras, para começar um novo parágrafo é necessário deixar uma linha em branco;
  • \(\LaTeX\) ignora o símbolo \(\%\), o mesmo é reservado para a inclusão de comentários no arquivo fonte;
  • Os erros de sintaxe são comuns quando você escreve um arquivo fonte, os mesmos são parte da vida diária dos usuários iniciantes. Quando \(\LaTeX\) encontra um erro na compilação, ele para o processo e mostra na tela uma mensagem de erro. A mesma mensagem você encontrará no arquivo .log. A experiência acumulada permitirá corrigir os erros mais rapidamente;

Tipos de de comandos

Todo comando de \(\LaTeX\) requer o símbolo \ (backslash) seguido de uma sequência de uma ou mais letras (maiúsculas ou minúsculas).

Qualquer usuário pode definir seus próprios comandos, seguindo certas regras de sinstaxe. Dessa forma, podem se distinguir quatro tipos de comandos:

  • Comandos simples: São comandos da forma \<nome_do_comando> e são utilizados para produzir símbolos particulares ou efeitos diretos no texto. Por exemplo:

    • \quad: produz um espaço horizontal do tamanho da letra M (na fonte utilizada no momento);
    • \qquad: equivale a dois \quad;
    • \  : equivale a um espaçamento médio ocupado por uma letra;
  • Comandos com um ou mais argumentos: São comandos da forma \<nome_do_comando>[<opções>]{...}{...}...{...}, onde {...} representa os valores dos argumentos e [opções] as opções do comando. Um exemplo típoco é o comando \documentclass[12pt,draft]{book};
  • Declarações globais: São comandos sem argumentos e limitados por chaves, por exemplo: {\it <texto>}. Quando se eliminam as chaves o comando se trona global, i.e., afetará todo o documento a partir do uso do comando. Para suspender uma declaração global é necessário usar uma declaração contrária, por exemplo \large (aumenta o tamanho da fonte), \normalsize retorna ao tamanho original da fonte;
  • Ambientes: São da forma \begin{...} \end{...}. Os comandos globais utilizados dentro dos ambientes só tem efeito local. Exemplo:
\begin{enumerate}
  \item Primeiro item
  \item Segundo item
\end{enumerate}

Gerenciamento de referências bibliográficas

Quando se trata de sistemas de gerenciamento de bibliografias, existem três opções principais em \(\LaTeX\): bibTeX , natbib e bibLaTeX. Embora os três utilizem arquivos .bib, eles oferecem diferentes comandos, estilos, tipos de dados e opções de atributos.

O biblatex é um pacote moderno para gerenciar bibliografias no \(\LaTeX\), oferecendo maior flexibilidade e suporte para processar arquivos .bib. Ele simplifica a personalização de estilos (autor-data, numérico, ABNT) e facilita o manuseio de caracteres especiais. A estrutura utiliza um arquivo .bib separado, carregado no preâmbulo, e o comando para exibir as referências.

Para referenciar um documento em um arquivo \(\LaTeX\), deve-se criar um arquivo de banco de dados bibliográficos, de extensão .bib. Dentro desse arquivo, as referências devem indicar seus campos obrigatórios e podem apresentar campos opcionais, caso o autor o deseje. No início de cada referência, deve-se colocar o caractere @ (arroba), seguido do tipo de documento que se planeja referenciar:

% Conteúdo do arquivo .bib
@book{mittelbach2004latex,
  title={The LATEX companion},
  author={Mittelbach, Frank and Goossens, Michel and Braams, Johannes and Carlisle, David and Rowley, Chris},
  year={2004},
  publisher={Addison-Wesley Professional}
}

@article{borges2016geometric,
  title={A geometric time series model with inflated-parameter Bernoulli counting series},
  author={Borges, Patrick and Molinares, Fabio Fajardo and Bourguignon, Marcelo},
  journal={Statistics \& Probability Letters},
  volume={119},
  pages={264--272},
  year={2016},
  publisher={Elsevier}
}
